Arch + i3, без мусора.

BratanOS — это Arch Linux с простотой pacman, элегантностью i3wm и дисциплиной NixOS — но без сложности последнего. Встроенный tidy не даёт сиротам, устаревшему кэшу и старым ядрам копиться.

2. Записать на USB

Выбери ОС, с которой ты сейчас работаешь:

Найди USB-устройство через lsblk. Подставь sdX ниже — не партицию, а весь диск.

sudo dd if=bratanos.iso of=/dev/sdX bs=4M status=progress conv=fsync
sudo sync

Это обычная live-флешка. Каждый ребут возвращает её в исходное состояние. Если хочешь, чтобы изменения сохранялись — открой вкладку «Флешка с памятью».

Найди диск через diskutil list, размонтируй и пиши dd:

diskutil list
diskutil unmountDisk /dev/diskN
sudo dd if=bratanos.iso of=/dev/rdiskN bs=4m
sync

Или возьми balenaEtcher, если терминал пугает.

Любой из вариантов:

  • Rufus — режим «DD image».
  • Ventoy — кинуть ISO на флешку с Ventoy.
  • balenaEtcher — выбрать, нажать, готово.

Сделать так, чтобы BratanOS реально жил на флешке: установленные пакеты, ~/.config, файлы в $HOME — всё переживает ребут.

sudo bratan-flash-persistent bratanos.iso /dev/sdX

Что делает скрипт:

  1. dd-ит ISO на флешку.
  2. Из оставшегося свободного места делает второй раздел в ext4 с меткой BRATAN_PERSIST.
  3. При следующей загрузке выбираешь «BratanOS (persistent)» в меню загрузчика — ядро монтирует этот раздел как writable overlay.

Скрипт лежит и внутри live-ISO, поэтому, загрузившись с обычной live-флешки, ты можешь сразу записать вторую — уже с памятью.

BratanOS Flasher — наш собственный аналог balenaEtcher: выбери ISO, выбери флешку, смотри прогресс. Написан на Tauri (Rust + web).

# на BratanOS или Arch:
git clone https://github.com/blessblissmari/bratanos
cd bratanos/installer
sudo bratan-flasher

Linux-бэкенд работает уже сейчас; macOS и Windows — в разработке (заглушки за общим trait-ом).

Почему BratanOS

Все плюсы кратко. Ничего из этого не требует учить новый инструмент.

⌬

Чистый Arch под капотом

Тот же pacman, та же Wiki, тот же rolling release. Мы не форкаем ядро и не изобретаем новый формат пакетов.

Самоочистка

bratan-tidy встроен в pacman и в еженедельный systemd-таймер. Сироты, устаревший кэш и старые ядра не накапливаются.

Как работает tidy

Три слоя чистки, всё на pacman + systemd — никакого нового пакетного менеджера.

после каждого удаления

Хук PostTransaction в pacman после любого pacman -R запускает bratan-tidy --auto — сироты и кэш улетают сразу.

еженедельный таймер

Таймер systemd запускает то же самое раз в неделю (idle-class IO, только от сети) — даже забытая машина остаётся чистой.

по требованию

bratan-tidy --status покажет, сколько можно освободить; --apply чистит; --auto — неинтерактивный режим для хуков.

AUR через обычный pacman

Никаких новых команд. pacman обёрнут так, что отсутствующие пакеты прозрачно тянутся из AUR.

Большая часть популярных AUR-пакетов также приходит готовыми бинарниками через Chaotic-AUR, который включён по умолчанию — компиляция вообще не нужна.

В разработке — экосистема bratan-*

Набор первопартийных приложений, все темизированы и подобраны под BratanOS. Каждое — отдельный репозиторий, ставится через обычный pacman, как только зарелизим.

bratan-flasher готово · v0.1

USB-флешер в стиле balenaEtcher на Tauri (Rust + web). Уже в репо в installer/ — Linux-бэкенд полностью рабочий.

bratan-recorder готово · v0.2

Запись экрана и микрофона в один клик, на клавише Print. Обёртка над wf-recorder (Wayland) и ffmpeg (X11). Складывает в ~/Videos/bratan-recorder/.

bratan-photos готово · v0.2

Быстрый просмотрщик (imv) + лёгкий редактор: поворот, отражение, интерактивный кроп (через slop), ресайз, конвертация форматов — всё через ImageMagick.

bratan-music готово · v0.2

MPD + ncmpcpp с Catppuccin-конфигом и биндами i3 под медиа-клавиши. bratan-music setup генерит рабочий конфиг в один проход.

bratan-mail готово · v0.2

Thunderbird с профилем BratanOS: тёмная тема, удалённые картинки блокируются, телеметрия отключена, GPG готов, Catppuccin userChrome.css.

bratan-browser готово · v0.2

Обёртка над Firefox / LibreWolf с системным policies.json: телеметрия выкл., uBlock Origin предустановлен, DuckDuckGo по умолчанию, Catppuccin chrome.

bratan-office готово · v0.2

LibreOffice с Catppuccin-овым registrymodifications.xcu, шаблоном BratanOS и экспортом в PDF одной командой bratan-office pdf FILE.

bratan-store планируется

Графический фронт для pacman + Chaotic-AUR + AUR. Поиск, установка, обновления, чистка — всё кликабельно. Для тех, кто хочет мощь Arch с GUI.

bratan-installer планируется

Графическая альтернатива archinstall: дефолты BratanOS уже выбраны (i3, ly, tidy, Chaotic-AUR), двуязычный интерфейс, шифрованный root по умолчанию.

bratan-cloud планируется

Опциональная синхронизация dotfiles и состояния. Идёт с рецептом self-hosted-бэкенда; либо просто укажи свой git remote.

FAQ

Почему не просто NixOS?

Nix решает проблему, но цена — новый язык, derivations, flakes и кривая обучения. BratanOS сохраняет простоту Arch и просто наводит порядок в том, что уже есть.

Это реально отдельный дистр или просто конфиг?

Это downstream Arch — те же пакеты, те же ядра, тот же pacman. «Дистр» — это профиль archiso, набор инструментов bratan-* и подобранные дефолты (i3, ly, GRUB-тема, Chaotic-AUR из коробки).

Можно поставить bratan-tidy на чистый Arch без переустановки?

Да. Клонируй репо и сделай sudo make install-tidy — он просто положит скрипт + systemd-юнит + pacman-хук на место.

Что в v0.2 по сравнению с v0.1?

v0.1 это сам дистрибутив + bratan-flasher. v0.2 добавляет шесть первопартийных приложений: bratan-recorder, bratan-photos, bratan-music, bratan-mail, bratan-browser и bratan-office — все уже в live-ISO по умолчанию. В roadmap остаётся: bratan-store, bratan-installer и bratan-cloud.
