Arch + i3, no trash.

BratanOS is Arch Linux with the simplicity of pacman, the elegance of i3wm, and the discipline of NixOS — minus the complexity. Built-in tidy means orphans, stale caches and old kernels never pile up.

2. Flash to USB

Pick the OS you're on right now:

Find the USB device with lsblk. Replace sdX below — NOT a partition.

sudo dd if=bratanos.iso of=/dev/sdX bs=4M status=progress conv=fsync
sudo sync

This produces a plain live USB. Every reboot resets to factory. Want changes to stick? See the Persistent USB tab.

Find the disk with diskutil list, unmount it, then dd:

diskutil list
diskutil unmountDisk /dev/diskN
sudo dd if=bratanos.iso of=/dev/rdiskN bs=4m
sync

Or use balenaEtcher if the CLI scares you.

Use one of:

  • Rufus — pick "DD image" mode.
  • Ventoy — drop the ISO onto a Ventoy stick.
  • balenaEtcher — point, click, flash.

Make BratanOS actually live on the USB stick — installed packages, ~/.config tweaks and files in $HOME all survive reboots.

sudo bratan-flash-persistent bratanos.iso /dev/sdX

What it does, in three steps:

  1. dds the ISO onto the stick.
  2. Carves the leftover space into a second ext4 partition labeled BRATAN_PERSIST.
  3. On next boot, pick "BratanOS (persistent)" in the bootloader menu — the kernel mounts that partition as the writable overlay.

The script ships inside the live ISO too, so once you've booted a plain live stick, you can use it to flash another one.

The BratanOS Flasher is our own balenaEtcher-style app: pick an ISO, pick a USB, watch a progress bar. Built with Tauri (Rust + web).

# on a BratanOS or Arch machine:
git clone https://github.com/blessblissmari/bratanos
cd bratanos/installer
sudo bratan-flasher

Linux is fully implemented today; macOS/Windows backends are scaffolded.

How tidy works

Three layers of cleanup, all using just pacman + systemd — no new package manager.

after every removal

A pacman PostTransaction hook runs bratan-tidy --auto after any pacman -R, dropping orphans + cache slack on the spot.

weekly timer

A systemd timer runs the same job once per week (idle-class IO, only on AC power), so even a never-touched box stays clean.

on-demand

bratan-tidy --status shows reclaimable space; --apply cleans; --auto is the non-interactive variant for hooks.

AUR via plain pacman

No new commands to learn. pacman is wrapped so missing packages are pulled from AUR transparently.

$ sudo pacman -S brave-bin
:: [bratanos] brave-bin not in sync repos — falling back to AUR via paru
:: building brave-bin via paru…
✓ brave-bin installed

Most popular AUR packages also ship as prebuilt binaries via Chaotic-AUR, enabled out of the box, so you skip compilation entirely.

FAQ

Why not just use NixOS?

Nix solves the problem, but the cost is a brand-new language, derivations, flakes and learning curve. BratanOS keeps Arch's simplicity and just disciplines what already exists.

Is it actually a separate distro or just a config?

It's a downstream of Arch — same packages, same kernels, same pacman. The "distro" is the archiso build profile, the bratan-* tools, and the curated defaults (i3, ly, GRUB theme, Chaotic-AUR enabled).

Can I install bratan-tidy on plain Arch without reinstalling?

Yes. Clone the repo and sudo make install-tidy — it just drops the script + systemd unit + pacman hook into place.

What's in v0.2 vs v0.1?

v0.1 shipped the distro itself plus bratan-flasher. v0.2 adds six more first-party apps: bratan-recorder, bratan-photos, bratan-music, bratan-mail, bratan-browser and bratan-office — all installed by default in the live ISO. Still on the roadmap: bratan-store, bratan-installer and bratan-cloud.
